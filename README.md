# 10,000 Hours of Machine Learning

A long-term challenge to spend 10,000 deliberate hours becoming a professional Machine Learning and Deep Learning engineer.

The goal is not simply to accumulate hours, but to develop real-world skills through learning, implementation, experimentation, research, and projects.

## Goal

Become capable of designing, training, evaluating, and deploying machine learning and deep learning systems professionally.

Long-term target:

**10,000 deliberate hours of ML/AI engineering practice.**

Career target:

**Become job-ready well before reaching 10,000 hours.**

## Progress

**Current Hours:** 0 / 10,000

## Challenge Rules

An hour counts when I am actively improving my ML/AI skills through:

- studying
- coding
- implementing algorithms
- solving problems
- running experiments
- building projects
- reading and reproducing papers
- debugging
- ML engineering
- interview preparation

Passive consumption does not automatically count.

The objective is deliberate practice, not simply time spent.
