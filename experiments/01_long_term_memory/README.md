# Sequence Models Experiement

## 1. Problem Statement

> How do vanilla RNNs, LSTMs, and GRUs differ in learning, retaining, and generalizing long-term dependencies?

## 2. Hypotheses

- Vanilla RNN performance will degrade more as sequences get longer.
- LSTM and GRU should perserve information better.
- All three may struggle when tested far beyond the training sequence length.
